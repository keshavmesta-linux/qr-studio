# QR Studio 🚀

A responsive QR code generator built with Python, Flask, HTML, and CSS.

## ✨ Features

- Generate QR codes from text and URLs
- Customize QR code colors
- Choose QR code size
- Download QR codes as PNG images
- Mobile-friendly interface

## 🛠️ Technologies

- Python
- Flask
- qrcode
- Pillow
- HTML5
- CSS3

## 📁 Project Structure

    qr-studio/
    ├── app.py
    ├── requirements.txt
    ├── README.md
    ├── .gitignore
    ├── templates/
    │   └── index.html
    └── static/
        └── style.css

## ⚙️ Installation

Install Python 3, then install the dependencies:

    pip install -r requirements.txt

## ▶️ Run the application

    python app.py

Open this address in your browser:

    http://127.0.0.1:5000

## 🔒 Privacy

QR codes are generated by the application. Do not enter sensitive information into QR codes that you plan to share publicly.
